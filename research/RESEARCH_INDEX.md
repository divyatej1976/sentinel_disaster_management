# SentinelAI v2 Research Workspace

This directory contains the product/research artifacts that must be completed before SentinelAI v2 implementation.

## Workflow

1. Market & ecosystem research
2. Competitive landscape
3. Research/literature review
4. Data/API/standards feasibility
5. User/persona analysis
6. Market-gap analysis
7. Product model options and scoring
8. Final product definition / PRD
9. Sentinel v1 → v2 gap analysis
10. Requirements
11. Architecture
12. Data architecture
13. Agent/tool architecture
14. User flows and wireframes
15. Implementation plan
16. Evaluation plan
17. Implementation
18. Validation and final documentation

## Current artifacts

- `SENTINEL_MARKET_RESEARCH.md` — initial market/ecosystem research and provisional product-model analysis.

## Rule

**No production-code changes should be made as part of the v2 redesign until the product model is finalized from the research artifacts.**

Each major product/architecture decision should be recorded in the relevant artifact and in a decision log so the final implementation remains traceable to the research.
