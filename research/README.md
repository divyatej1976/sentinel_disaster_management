# Sentinel v2 Research

This directory contains the research and product-design artifacts for Sentinel v2.

## Workflow

1. Market and ecosystem research
2. Competitive landscape
3. User personas and Jobs-to-be-Done
4. Literature and technical research
5. Data/API/standards feasibility
6. Market-gap analysis
7. Product model options and weighted scoring
8. Final product definition / PRD
9. Sentinel v1 → v2 gap analysis
10. Requirements
11. Architecture
12. Data and agent/tool architecture
13. User flows and wireframes
14. Implementation plan
15. Evaluation plan
16. Implementation
17. Validation and final documentation

**Rule:** Product and architecture decisions should be traceable to the research. Production implementation begins only after the new Sentinel model is finalized.
