# Sentinel v2 — Market Research Method

## Objective

Determine the strongest product model for Sentinel before changing production architecture or code.

## Research questions

1. Who already solves disaster warning, mapping, forecasting, EOC coordination and crisis communication?
2. Which parts of the disaster-management workflow remain fragmented?
3. What can current AI systems reliably add beyond existing specialist systems?
4. Which user problems are important enough to justify a new product?
5. Which capabilities are feasible using accessible data and APIs?
6. What would make Sentinel technically differentiated rather than a dashboard wrapper?
7. What safety and human-authorization boundaries are required?

## Evidence hierarchy

1. Official government/agency documentation
2. Standards organizations and authoritative technical documentation
3. Peer-reviewed / research papers and benchmarks
4. Product documentation from established vendors
5. Open-source repositories and technical write-ups
6. General commentary only when primary evidence is unavailable

## Comparison dimensions

- Primary user
- Problem solved
- Hazard coverage
- Warning capability
- Forecasting capability
- Geospatial capability
- Exposure/impact assessment
- Resource management
- Evacuation/route planning
- AI/agent capability
- Evidence/provenance
- Human-in-the-loop controls
- Workflow/task management
- Real-time data
- Interoperability
- Evaluation evidence
- Geographic focus
- Data accessibility
- Deployment complexity
- Differentiation opportunity

## Decision rule

A Sentinel feature should be prioritized only when it scores well on a combination of:

**User value × differentiation × evidence × feasibility × portfolio/research value**

Features that are impressive but already commoditized, unsafe, data-infeasible, or disconnected from a clear user job should be deprioritized.

## Current hypothesis

The strongest direction discovered so far is an evidence-grounded, geospatial, human-in-the-loop disaster operations decision-support platform. This remains a hypothesis until the remaining market, persona, feasibility and model-scoring work is complete.
